# Visual identity
- Black/graphite base for low-glare operations.
- Cyan/blue for data and system info.
- Green for connected/safe.
- Amber for warning.
- Red for risk/blocked.
- Tactical panel borders and terminal-style logs.

# Layout rules
- Header + nav + panel grid hierarchy.
- Primary command center above supporting diagnostics.
- Dense but readable spacing for daily use.

# Spacing
- 4px base unit.
- Tight cards: 12–16px padding.
- Section gaps: 16–24px.

# Typography
- Inter for UI text.
- JetBrains Mono for logs/status values.

# Components
- Tactical HUD panels
- Buttons (primary/secondary/warn)
- Command input
- Status chips
- Risk badges
- Council cards
- Log streams
- Approval cards
- Empty/error states

# Accessibility
- Maintain readable contrast.
- Do not encode critical status with color only.
- Keep keyboard focus styles visible.

# Guardrails
- Do not copy anime/copyrighted assets.
- Do not copy proprietary brand designs.
- Keep all generated UI original.
