Manual push commands from an external Command Prompt or PowerShell with Git installed:

1. Open the project:

cd "C:\Users\pixel\Documents\Codex\Projects\ai receptionist"

2. Initialize Git only if .git does not already exist:

git init

3. Connect the production repository:

git remote add origin https://github.com/jhicoolin/nexcall.git

If origin already exists, update it:

git remote set-url origin https://github.com/jhicoolin/nexcall.git

4. Confirm the branch:

git branch -M main

5. Stage everything needed for launch:

git add .

6. Commit:

git commit -m "feat: launch landing page with production cal v2 route and outbound call modal"

7. Push to the Vercel-linked main branch:

git push -u origin main

8. In Vercel:

- Open the nexcall project.
- Confirm the GitHub repo is jhicoolin/nexcall.
- Confirm the production branch is main.
- Add the required environment variables above.
- Redeploy the latest main branch commit if it does not deploy automatically.

Post-deploy smoke checks:

1. Open https://nexcall.one
2. Click Call Demo.
3. Enter a real phone number in +1 format.
4. Confirm the modal shows Calling Now.
5. Confirm the ElevenLabs conversation starts from Ms. Lisa.
6. Trigger a test booking phrase in the call.
7. Confirm Cal.com receives a booking payload through /api/calendar.

Important:

Do not commit .env.local or real API keys. Store secrets only in Vercel Environment Variables.
