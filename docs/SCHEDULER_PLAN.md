# MISATO Scheduler (Scaffold)

## Goal
Define controlled scheduled runs for safe recurring checks and reports.

## v1 Rules
- Disabled by default.
- Jobs are mock/planning unless owner explicitly enables.
- Any risky class action auto-routes to Approval Gate.

## Future
- Cron-based safe jobs (summaries, backlog hygiene)
- Event hooks with immutable logs
- Owner pause/resume controls
