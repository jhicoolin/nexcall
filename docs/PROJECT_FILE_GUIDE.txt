AI RECEPTIONIST - PROJECT FILE GUIDE
Last updated: May 13, 2026

This guide explains what each project file is for. Most operational notes now live in `docs/` so the project root stays clean.

Important:
Some files must keep their current names because Next.js uses file names for routing.
For example, app/page.tsx controls the homepage route and app/api/*/route.ts controls API routes.
Renaming those files would break the app.

docs/PROJECT_FILE_GUIDE.txt

Generated portable source bundles. These are useful for handoff/upload, but they are ignored by git.

Template for environment variables. Copy this into .env.local and fill in your real Stripe, Twilio, webhook, and demo-audio values.

Project name, scripts, and dependency list.

Next.js configuration, including allowed remote image hosts.

Tailwind CSS design configuration, including font stacks, theme colors, and content paths.

postcss.config.mjs
PostCSS/Tailwind build pipeline config.

tsconfig.json
TypeScript configuration for the app.

next-env.d.ts
Auto-generated Next.js TypeScript definitions. Do not edit manually.

============================================================
API ROUTES
============================================================

app/api/checkout/route.ts
Creates Stripe Checkout Sessions using your Stripe price IDs.

app/api/ai/respond/route.ts
Tenant-aware AI turn processor called by the Twilio Media Stream server. It loads the client prompt, runs Hugging Face STT/LLM/TTS, detects booking intent, and returns Twilio-ready audio.

app/api/stripe/webhook/route.ts
Receives Stripe checkout.session.completed events and optionally forwards them to an onboarding webhook.

app/api/leads/route.ts
Receives the website lead form and forwards it to LEAD_WEBHOOK_URL when configured.

app/api/chat/huggingface/route.ts
Answers visitor chat questions with the tenant-aware front-desk chat engine. The route name is kept for backwards compatibility.

app/api/calendar-booking/route.ts
Receives booking data from the voice agent and forwards it to the matching client's calendar webhook or CALENDAR_WEBHOOK_URL.

app/api/twilio/voice/route.ts
Returns TwiML for incoming Twilio calls and forwards calls to the matching client's voice-agent webhook or VOICE_AGENT_WEBHOOK_URL.

app/api/clients/lookup/route.ts
Protected lookup route for voice-agent platforms or internal tools. Finds a client by clientId or phone number without exposing webhook URLs.

app/api/tts/huggingface/route.ts
Optional server-side Hugging Face TTS route. It keeps the Hugging Face token on the server and returns audio for approved demo scenarios only when enabled. It rejects custom visitor text.

============================================================
LIBRARY FILES
============================================================

lib/checkout-plans.ts
Maps pricing plan IDs to Stripe price ID environment variables.

lib/client-directory.ts
Compatibility export layer that points older imports to the database-first tenant repository.

lib/tenant-repository.ts
Loads tenants from Postgres through Prisma, decrypts tenant webhooks, and maps phone numbers to voice, lead, calendar, and CRM settings.

lib/twilio-signature.ts
Validates Twilio webhook signatures when TWILIO_AUTH_TOKEN is configured.

lib/twilio-twiml.ts
Builds Twilio XML responses for fallback messages, redirects, and bidirectional Media Streams.

lib/audio-codecs.ts
Converts Twilio mu-law audio to WAV for speech recognition and converts Hugging Face WAV back to Twilio mu-law base64.

lib/booking-intent.ts
Extracts booking intent from caller/assistant text and fires the matching client's calendar webhook.

lib/huggingface-receptionist-pipeline.ts
Runs the tenant-specific speech-to-text, master prompt injection, LLM response, safety shutoff, TTS, booking detection, and Twilio audio conversion pipeline.

lib/live-chat-knowledge.ts
Approved site context and fallback answers for the collapsed live chat.

============================================================
SERVICES
============================================================

services/receptionist/master-system-prompt.ts
Builds the master AI receptionist prompt with tenant rules, Service Profit Chain customer-service standards, no-hallucination rules, and dynamic business knowledge injection.

services/receptionist/company-knowledge.ts
Generalized industry knowledge layer for many company types. It selects vocabulary, intake fields, allowed actions, and escalation rules for cleaning, home services, legal, healthcare, restaurant, auto, retail, real estate, finance, and general business use cases.

services/receptionist/safety-policy.ts
Central safety kill-switch used by web chat and voice turns. If abusive or inappropriate language is detected, the assistant gives a polite sign-off and marks the conversation terminated.

services/receptionist/web-chat-engine.ts
Humanized website chat engine with 1M+ approved response combinations, 2-3 keyword routing, industry-specific answers, business-lens fallback logic, randomized phrasing, and safety termination.

lib/security.ts
Shared request validation, sanitization, URL safety, and API error helpers.

lib/huggingface-voice-lab.ts
Hugging Face voice model shortlist, scenario-to-model mapping, approved scenario scripts, and small helpers used by the site and TTS route.
