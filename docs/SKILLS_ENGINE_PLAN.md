# MISATO Skills Engine (Scaffold)

## Goal
Define reusable skill packs for council agents (strategy, backend, security, QA, deploy, ops).

## v1 Scope
- Skill metadata schema
- Versioning strategy
- Safety tags (`safe`, `approval-required`, `high-risk`)
- Runtime selection rules (mock mode first)

## Non-goals
- No autonomous live execution in v1.
- No secret-bearing skill payloads.
